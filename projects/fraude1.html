Objectif et contexte

Ce projet vise à détecter et analyser différents types de fraudes dans les transactions mobile money en Afrique de l'Ouest. Nous avons simulé un ensemble de données réalistes contenant 5,015 transactions et implémenté des règles métier spécifiques pour identifier quatre types de fraudes courantes dans ce contexte.

Implémentation technique

Règles de détection Social Engineering
fraude1.py - Détection Social Engineering Python 

# Analyse des destinataires suspects
receiver_features = (
    df_fraude.groupby("receiver_id")
    .agg(
        receiver_tx_count=("transaction_id", "count"),
        receiver_total_amount=("amount", "sum"),
        receiver_avg_amount=("amount", "mean"),
        receiver_min_amount=("amount", "min"),
        receiver_std_amount=("amount", "std"),
        receiver_unique_receivers=("sender_id", "nunique"),
        receiver_first_tx=("timestamp", "min"),
        receiver_last_tx=("timestamp", "max")
    )
    .reset_index()
)

# Calcul de la durée d'activité
receiver_features['sender_activity_duration'] = (
    (receiver_features['receiver_last_tx'] - receiver_features['receiver_first_tx'])
    .dt.total_seconds() / 60
)

# Sélection des comptes suspects
compte_suspect = receiver_features[
    (receiver_features['receiver_tx_count'] > 10) &
    (receiver_features['receiver_unique_receivers'] > 10)
]

print("Comptes suspects détectés (Social Engineering) :")
print(compte_suspect[['receiver_id', 'receiver_tx_count', 'receiver_total_amount', 
                      'receiver_unique_receivers', 'sender_activity_duration']])
